# いちぽる履修カラー

広島市立大学の UNIPA（いちぽる / UNIVERSAL PASSPORT RX）で、履修登録とシラバス検索の科目を色分けする Chrome 拡張機能です。

- 自学科
- 他学科
- 共通科目（全学共通・教養・外国語系など）

設定画面は Chakra UI のモーダルです。判定も保存もブラウザの中だけで完結します。

## プライバシー

この拡張は、科目データ・ページの内容・クッキーを、開発者のサーバを含む第三者へ送りません。

- 計測、遠隔の設定取得、外部フォント、CDN はありません
- 設定は `chrome.storage.local` に保存します。授業コードの索引は拡張に同梱した JSON で、実行時には取りにいきません
- 科目のキャッシュは `chrome.storage.session`（ブラウザを閉じると消える）に、取り出した項目だけを残します
- ネットワークを見る処理は、いちぽる自身が行った同一オリジンの応答を読むだけです
- 行のリンク先を追加で開く処理は動きません。今見ている表と、ページ自身が受け取った同一オリジンの応答だけを使います

## インストール

```bash
npm install
npm test
npm run build
```

1. Chrome で `chrome://extensions` を開く
2. デベロッパーモードをオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの `dist/` を選ぶ
4. セッションのある履修登録（`/uprx/up/**/*.xhtml`）を開くと色が付く
5. いちぽるを開いた状態でツールバーのアイコンを押すと、設定モーダルが開きます。画面左下の「色分け設定」からも同じモーダルが開きます

この拡張はログインしません。認証の入口は `https://ichipol.g.hiroshima-cu.ac.jp/uprx/ShibbolethAuthServlet` です。セッションがない状態で画面の奥の URL を開いても通りません。別の場所でログインすると、こちらのセッションが切れることがあります。

設定を変えたあとは、開いている一覧にそのまま反映されます。反映されないときはページを再読み込みしてください。

## 学科の設定

設定モーダルの「自分の所属」で、学部と学科を選びます。候補は公開されている学修の手引き（2024年度入学生版）の学部構成です。

- 国際学部: 国際学科
- 情報科学部: 学部配属（1年・学科決定前） / 情報工学科 / 知能工学科 / システム工学科 / 医用情報科学科
- 芸術学部: 美術学科（日本画・油絵・彫刻）/ デザイン工芸学科

一覧に無い名称は「その他（手入力）」から入れます。選んだ学科の講義が自学科、別学科の講義が他学科になります。所属が空のあいだは、共通科目だけ色が付きます。学科を空にして学部だけ選ぶと、その学部だけで開講されている科目を自学科にします。

情報科学部の1年は「学部配属」を選びます。学科の付いていない情報科学部の専門科目が自学科の色、学科がある科目（例: 情報工学科）は他学科の色です。2年以降に学科が決まったら、その学科へ変えて保存します。

## 色の変更

モーダルの「色の変更」で、次の3色を選べます。

| 項目 | 初期の色 | 意味 |
| --- | --- | --- |
| 自学科の講義 | 緑 | 設定した学科と開講学科が一致 |
| 他学科の講義 | 橙 | 開講学科が自分の学科と異なる |
| 共通科目 | 青 | 全学共通・教養・外国語系など |

凡例の見本が、選んだ色ですぐ変わります。「画面に凡例を出す」をオフにすると、履修一覧の左下の凡例だけ隠れます。左端の線は背景色から自動で濃くします。

行にマウスを乗せると、なぜその色になったかの短い理由が出ます。他学科のときは、開講している学科か学部を示します。

## 判定

上から順に決めます。設定画面で変えるのは所属と色です。

1. 保存データに上書きルールが残っていれば、それが先
2. 同梱の授業コード索引。共通は共通科目。専門科目は、設定した学部と一致し、学科があればその学科とも一致するとき自学科。学科の無い学部開講は自学科。学部が違えば他学科。索引に無いコードは他学科にせず、無色のままにする
3. 索引に無い科目で、共通・教養・全学共通・外国語系・一般情報処理・保健体育・キャリア形成などの標識
4. 開講学科が、設定した学科と一致 → 自学科
5. 学科名がなく、設定した学部だけの開講 → 自学科
6. 開講所属が取れて、一致しない → 他学科
7. それ以外 → 未判定（色を付けない）

「学部共通科目」は全学の共通科目にしません。情報科学部の学生にとっての学部共通は、学部開講として扱います。

学科名のゆらぎ（空白、`情報科学部情報工学科` のような連結）は吸収します。専攻まで設定した場合、別専攻は他学科、専攻が書かれていない同じ学科の科目は自学科です。

索引に無い授業コードは、他学科とは決めません。色を付けないままにします。セルの括弧が学科そのものか、今開いているシラバスの履修対象に学科があるときだけ、その信号で塗ります。所属が空のあいだは、共通科目だけ色が付きます。

## 履修登録の画面

ログイン済みの実測（2026-09-25）です。色を付ける主対象は履修登録です。

- ダッシュボード: `https://ichipol.g.hiroshima-cu.ac.jp/uprx/up/pk/pky001/Pky00102.xhtml`
- 履修登録: `https://ichipol.g.hiroshima-cu.ac.jp/uprx/up/bs/bsa001/Bsa00101.xhtml`
- シラバスは別ページではなく、同じ URL のダイアログ `[role="dialog"][aria-label="シラバス照会"]`

時間割は検索結果の行ではなく、`aria-label` が「2026年度 後期」のようなグループの中の表です。列は月〜金、行は時限です。セルには科目名、教員、教室、8桁の授業コード、単位、`必修` や `複数回` が入ります。タブ「授業を選択」「授業を追加」は文言で見ます。`j_idt*` の id は再描画で変わるので使いません。

開講学部・学科・科目区分の列はありません。判定は次です。

1. 同梱索引 `data/courses-2026-kouki.json` に授業コードがあるとき
   - `category` が `common` → 共通科目
   - `category` が `faculty` で、設定した学部と一致し、`department` が空 → 自学科の色（学部開講）
   - `department` があり、設定した学科と一致 → 自学科の色。同じ学部の別学科 → 他学科の色
   - 索引にあるが学部が違う → 他学科の色
   - 索引に無いコードは他学科にせず、無色のままにする
2. 索引に無いコードで、科目名の括弧が学科そのもの（例: `（情報工学科）`）なら、その学科と自分の所属を比べます。`（イノベクラス）` は学科にしません
3. 開いているシラバスの「履修対象」「備考」に学科があるときも、その授業コードへ返します
4. `全学共通` などの文言がセルにあれば共通科目。単位集計の「全学共通」「他学科」はセルへ写しません

集中・実習の表（見出しが授業科目、教員氏名、教室、単位数、削除）は行を塗ります。PrimeFaces がタブやダイアログで DOM を差し替えたら、同じ規則でもう一度塗ります。科目一覧の JSON API は実測で見えていないので、DOM だけを読みます。閉じたシラバスダイアログを、履修登録の画面から開き直すことはしません。

差し替え口は `src/content/selectors.ts` の `LIVE_PAGE` です。

## 授業コード索引

拡張はシラバスを実行時に読みません。年度ごとの JSON を同梱し、時間割セルの授業コードで引きます。設定画面は、自分の所属（学部・学科）と3色だけです。

いまのファイルは `data/courses-2026-kouki.json`（2026年度後期、2026-09-27 更新、627件）です。内訳は全学共通 154、情報科学部 128、国際学部 252、芸術学部 93 です。このうち 390 件は `department` を持ちます。import は `src/content/syllabus-lookup.ts` にあります。授業コードの大文字小文字は区別しません。索引に無いコードは他学科に塗らず、無色のままにします。

毎年、ゲストのシラバス検索で作り直します。

- 入口: `https://ichipol.g.hiroshima-cu.ac.jp/uprx/up/pk/pky001/Pky00101.xhtml?guestlogin=Kmh006`
- 画面はシラバス照会 [Kmh006] / シラバス検索です
- 「科目授業種別」で `全学共通科目` と各学部の専門科目を検索し、授業コードを `courses` に集めます
- `全学共通科目` は `"category": "common"`
- `情報科学部専門科目` のような学部の専門科目は `"category": "faculty"` と `"faculty"`
- 講義・演習などの実施形態や単位互換は、この区別には使いません

シラバスの詳細画面に開講学科は無いので、学科は 2026-09-18 時点の学部時間割から足しています。専門科目として 1 学科、または一部の学科のシートにだけ載っている授業コードへ、その学科を `department` に入れます。複数学科のときは空白区切りです。全学科に載る学部開講（情報科学部では学部配属のシートにもある科目、芸術学部では全専攻にある科目）は `department` が null のままです。時間割に無かった 11 件も null です。

- ホスト: `https://ichipol.g.hiroshima-cu.ac.jp`（`ichipol.hiroshima-cu.ac.jp` と `*.g.hiroshima-cu.ac.jp` も対象）
- 認証の入口: `https://ichipol.g.hiroshima-cu.ac.jp/uprx/ShibbolethAuthServlet`（この画面では色分けしません）
- 大学サイト全体（`www.hiroshima-cu.ac.jp` など）には入れません

拡張から新しいバックエンドは作っていません。

## 構成

- `src/shared/classify.ts` — 判定
- `src/content/selectors.ts` — 履修登録の実測セレクタ（`LIVE_PAGE`）
- `src/content/registration.ts` — 時間割セル、シラバスダイアログ、学科の括弧
- `data/courses-2026-kouki.json` — 2026年度後期の授業コード索引（627件）。毎年差し替える
- `src/content/syllabus-lookup.ts` — 同梱 JSON を授業コードで引く
- `src/content/` — 一覧の検出、色付け、同一オリジン応答の観測
- `src/settings/` — Chakra UI の設定モーダル
- `src/background/index.ts` — ツールバーから設定を開く
